# Sean Ruan — Portfolio

A responsive, static portfolio inspired by the simplicity of the February 2026 thavlik.dev site. Original markup and styles, with Sean's introduction and projects. Uses HTML, CSS, and a small JavaScript enhancement; no package installation or build step.

## Preview

From this directory:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open http://localhost:8000. You can also open `index.html` directly; clipboard support depends on the browser and secure context.

## Edit

- `index.html`: biography, project cards, and contact links.
- `styles.css`: colors, typography, layout, and mobile styles.
- `script.js`: copy-email interaction and footer year.
- `assets/Sean_Ruan_Resume.pdf`: local résumé copy, not linked from the page.

The résumé PDF includes the contact details from the supplied original. Review the content and PDF before publishing. Team research is labeled and linked to its team repository.

## Hosting

Upload these static files to any static web host. No backend, database, API keys, or paid cloud infrastructure is required by the site. Nothing has been published automatically.
